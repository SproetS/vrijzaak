| File | Weight / style |
|------|----------------|
| `GAP Code/GAPCode-Regular.woff2` | 400 normal |
| `GAP Code/GAPCode-Italic.woff2` | 400 italic |
| `GAP Code/GAPCode-Bold.woff2` | 700 normal |
| `GAP Code/GAPCode-BoldItalic.woff2` | 700 italic |
