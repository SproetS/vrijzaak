# svg/ — UX-iconen en vectoren

Losse iconen, illustraties en UI-vectoren (niet het primaire logo — dat hoort in `logos/`).

## Afspraken

- Bestandsnaam duidelijk: `icon-cart.svg`, `icon-check.svg`, …  
- Bij voorkeur `currentColor` of tokens-kleuren (ink/accent) i.p.v. harde random hex.  
- Koppel aan component/pagina uit [docs/00-inventaris-bouw-ui.md](../../docs/00-inventaris-bouw-ui.md) waar relevant.  
- Programmeur neemt over naar Nuxt `app/assets` / `public` in de **bouwrepo**.
